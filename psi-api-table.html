Singapore PSI API

Quick reference for the pollutant and PSI fields documented in the supplied OpenAPI JSON.

Endpoint: GET https://api-open.data.gov.sg/v2/real-time/api/psi
Returns the latest reading by default, or readings for a requested date/time. Values are reported separately for East, West, North, South and Central Singapore.

Reading fields

Each field below has a value for each of the five regions. The source schema describes these readings in micrograms per cubic metre.
